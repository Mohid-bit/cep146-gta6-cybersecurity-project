## Project Overview
This project examines the September 2022 Rockstar Games security breach, during which confidential Grand Theft Auto VI development footage was leaked online. It explores what happened, the reported attack methods, the breach's impact, and cybersecurity lessons organizations can use to protect their systems and information.
